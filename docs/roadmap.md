# 開発ロードマップ

## 現在地

kendo-keiko.comは、スクレイピングの技術検証段階から、実際に掲載情報を増やして利用者に使ってもらう段階へ移行している。

現在の公開パイプラインは、次の2種類のイベントを統合する。

- DynamoDBに保存された自動取得イベント
- `data/manual_events.json`でGit管理する手動イベント

手動登録用CLI、イベント単位の参加条件・確認日、Step Functionsによる情報源単位の実行、監視通知まで整備済みである。

## 開発原則

- 大きな実装Issueは原則1件ずつ進める
- データ保全、利用者向け改善、情報追加を偏らせず交互に進める
- 自動化に固執せず、正確な情報を早く掲載できる方式を選ぶ
- 公式情報へのリンク、参加条件、最終確認日を保持する
- スクレイピング失敗や一時的な未検出で、既存イベントを即時削除しない
- 画面の機能を増やす前に、スマートフォンでの探しやすさを優先する
- 地図、アカウント、口コミなど運用負荷の大きい機能は後回しにする

## 優先順位

### 1. 覚えやすいブランド

サイト名、favicon、OGP画像、HTMLタイトル、サブコピーを一貫させる。

候補となるサイト名は「剣道稽古ナビ」。ドメイン `kendo-keiko.com` は維持し、検索結果では「オープン稽古会・合同稽古会を探せるサイト」であることが伝わる表現を残す。

比較的小さく独立した変更であり、サービスを覚えてもらう入口として先に実施する。

### 2. 一覧から「探せる画面」へ

Issue #26を、参加条件の表示だけでなく、次の検索体験を整備する主要UI/UX Issueとして扱う。

- 今週末、7日以内、今月などの日付ショートカット
- 地域による絞り込み
- 参加条件による絞り込み
- 団体・キーワード検索
- 参加条件、確認日、確認期限のカード表示
- 絞り込み解除と件数表示
- モバイルで押しやすいフィルタUI

本格的な月間カレンダーは別Issueとし、最初は既存一覧を探しやすくする。

### 3. 関東の掲載密度を上げる

地域・民間団体のEpic #9と、剣道連盟のEpic #12を継続的に進める。

当面は埼玉、東京、神奈川、千葉を中心とし、「関東なら毎週どこかの稽古を見つけられる」状態を目指す。団体ごとに個別Issueを作り、自動、半自動、手動のうち運用負荷に合う方式を選択する。

情報追加は一度に大量に行わず、1団体追加するたびに次を確認する。

- 公式情報を継続して確認できるか
- 参加条件を誤解なく表現できるか
- 月次確認の負荷が許容範囲か
- 公開パイプラインとサイト表示が正常か

### 4. 差分反映と掲載状態の安全管理

Issue #25では、取得元から消えたイベント、変更されたイベント、一時的に取得できなかったイベントを安全に扱う。

Issue #21で情報源単位の失敗分離、Retry、警告・失敗記録、アラート通知までは整備済みである。また、現在は取得できなかったイベントを即削除する実装ではなく、古い未来イベントが残る側に倒している。

そのため、#25は重要だが現時点の最優先にはせず、ブランドと検索UXを改善し、掲載情報を段階的に増やした後に着手する。掲載件数や更新頻度が増え、古い未来イベントの確認負荷が目立ち始めた場合は優先度を引き上げる。

### 5. 再訪につながる便利機能

検索UXの改善後、次の順で検討する。

1. イベント単位の「カレンダーに追加」と全件ICS
2. 月間カレンダービュー
3. 静的なイベント詳細ページ
4. 掲載依頼・修正連絡フォーム
5. AWS構成図と運用ランブックの整理

## 情報追加の運用負荷

- 手動掲載団体は月1回程度を目安に再確認する
- 月次確認が合計60〜90分以内なら手動掲載を継続する
- 月2時間を超えたら新しい手動団体の追加を一旦止める
- 運用負荷が増えた段階で、主催者投稿、半自動化、管理画面、収益化を再検討する

## 本番確認の基準

公開イベント総数は、開催日経過や取得元の更新によって変動するため固定値で判定しない。

更新後は次を確認する。

- Step Functionsの実行が成功している
- 情報源ごとの成功・警告・失敗件数が妥当である
- 追加対象団体のイベントが期待件数公開されている
- 団体別件数に不自然な増減がない
- 必須メタデータの欠損が0件である
- 公式URL、参加条件、確認日が表示用JSONに含まれる

## 完了済みの主要基盤

- S3 + CloudFrontによる静的サイト公開
- 独自ドメインと基本SEO
- レスポンシブな剣道向けデザイン
- 全日本剣道連盟、東京都剣道連盟、神奈川県剣道連盟などの自動取得
- Step Functionsによる情報源単位の定期実行
- CloudWatch AlarmとSNS通知
- イベント単位の取得方式・参加条件・確認日
- 管理者CLIによる手動イベント管理
- 眞心会の手動掲載
- 手動団体追加から本番公開までの標準手順
